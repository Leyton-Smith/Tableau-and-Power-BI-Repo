# Data Visualisation Projects Portfolio

## Overview

These projects were completed as part of a Data Technician Bootcamp and demonstrate practical experience in both **Power BI** and **Tableau** for data analysis, visualisation, and dashboard development. The projects focused on transforming retail and sales data into meaningful insights through interactive reports, dashboards, and data storytelling techniques.

---

# Power BI Project

## Project Overview

This Power BI project focused on analysing retail and sales data to uncover trends, track performance, and support business decision-making. The solution involved preparing and transforming data, creating calculated metrics, and designing interactive reports for end users.

## Skills Demonstrated

### Data Transformation & Cleaning
- Imported and prepared datasets using **Power Query**
- Cleaned and transformed raw data for analysis
- Managed data types and data quality issues
- Applied filtering and shaping techniques to improve data usability

### Data Modelling & DAX
- Created relationships between tables
- Developed **DAX Calculated Columns** for additional business metrics
- Built **DAX Measures** to calculate KPIs and performance indicators
- Used aggregation functions to support business reporting

### Interactive Reporting
- Designed interactive Power BI reports and dashboards
- Implemented **slicers and filters** for dynamic data exploration
- Created drill-through functionality to investigate specific business areas
- Enhanced user experience through interactive visuals

### Data Visualisation
Created a variety of visualisations including:

- **Bar Charts** for category and regional sales comparisons
- **Line Charts** for trend analysis over time
- **Pie Charts** for product and category contribution analysis
- **Map Visualisations** for geographical sales performance
- KPI cards and summary metrics for business monitoring

### Data Storytelling
- Organised insights into clear and engaging report pages
- Highlighted key trends, patterns, and business opportunities
- Used effective visual design principles to communicate findings
- Supported data-driven decision-making through insight-focused reporting

## Key Insights Explored

- Regional sales performance
- Product category profitability
- Revenue trends over time
- Customer purchasing patterns
- Geographic distribution of sales activity

## Tools & Technologies

- Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Modelling
- Interactive Dashboard Design

## Learning Outcomes

Through this project, I developed experience in:

- Data cleaning and preparation
- Power Query transformations
- Data modelling and relationships
- DAX calculations and measures
- Interactive report design
- Business-focused data storytelling

- Developed user-friendly reporting solutions

### Calculated Fields
- Created calculated fields to derive additional business metrics
- Performed custom calculations to support analysis

### Data Visualisation
